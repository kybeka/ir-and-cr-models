# MATLAB validation

The repository includes `runAtelierChecks.m` for numerical and interactive checks using the supplied data. Run from the repository root in MATLAB:

```matlab
addpath('tests');
runAtelierChecks;
```

The checks open and close figures, exercise controls, write temporary PCA variants next to the original script, and remove those variants afterward. Generated CSVs and the full yield curve video are saved under `results/generated/`. The last PCA variant is FRED monthly changes; rerun the original PCA script to regenerate its default GSW-level outputs.

## Checks

- PCA: GSW and FRED inputs, each with yield levels and monthly changes; finite outputs, orthonormal loadings, explained variance totals, diagonal factor covariance, exact full-component reconstruction, and dated output dimensions.
- Vasicek: finite fitted yields, valid mean-reversion parameters, consecutive monthly observations, agreement between the closed-form bond coefficient and numerical integration, the risk-premium relationship, and the estimated-parameter UI curves.
- Yield curves: first, middle, and latest slider positions; linear/log maturity axes; fixed/auto/log yield axes; playback; and MP4 export with a readable video and expected duration.

## Interpretation and limits

These checks establish execution and internal numerical consistency. They do not establish that the supplied datasets are correct, that the supplied reference PCA results were generated by these scripts, or that a one-factor Vasicek model fits the historical data closely.

The latest GSW month is partial because the snapshot ends on November 6, 2026. Monthly GSW aggregation selects the last available daily observation; the supplied FRED series are monthly observations. The Vasicek short rate uses TB3MS as a proxy.
